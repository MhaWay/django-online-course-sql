# Django Online Course (SQL and Databases final project)

Web application built with Python and Django (final project for IBM "Django Application Development with SQL and Databases").

## Features
- Models: Course, Lesson, Question, Choice, Submission
- Admin: QuestionInline, ChoiceInline, QuestionAdmin, LessonAdmin + 7 registered models (Course, Lesson, Question, Choice, Submission, User, Group)
- Views: index, about, course_details, submit, show_exam_result
- Mock exam: submits answers, scores them, shows Congratulations message with score and exam results
- Bootstrap 5 styling in templates
